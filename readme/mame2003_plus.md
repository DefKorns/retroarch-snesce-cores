## Options

The hmod installs the options it was tested with, and keeps yours if you changed them before.

- `Skip Disclaimer` and `Skip Warnings` are on, so a game starts without the copyright and warning screens.
- The rest are the core's defaults.

## High scores

`/etc/libretro/system/mame2003-plus/hiscore.dat` is the file from the core's repository, at the commit the core is built from.

## ROMs

Use a MAME 2003-Plus romset. No ROMs are included.

## Known issue

Mortal Kombat crackles on the console with this core. The KMFD core does the same, also with the RetroArch settings of the KMFD hmod and with a lower CPU Clock Scale, so it is not specific to this build.
