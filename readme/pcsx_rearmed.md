## Options

The hmod installs the options it was tested with, and keeps yours if you changed them before.

- `Enhanced Resolution` (`neon_enhancement_enable`) is on: the GPU renders at twice the resolution. In Final Fantasy VII it stayed at 60 FPS, in the field and in battle.
- `Threaded Rendering`, `DynaRec threading` and `Threaded SPU` are off. With the threads on, the same scene dropped to about 54 FPS on the console.

## BIOS

**No BIOS is included.** Games run without one, but compatibility is better with one. Put `scph5500.bin`, `scph5501.bin` and `scph5502.bin` in `/etc/libretro/system/`.
