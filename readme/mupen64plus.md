## Controls

The hmod installs the options and the remap it was tested with, and keeps yours if you changed them before.

| Pad button | N64 |
| --- | --- |
| A | A |
| B | B |
| Y | C1 |
| ZL | Z |
| L, R | L, R |
| Right stick | C buttons |
| Left stick, or the D-Pad | Control Stick |

`D-Pad as Control Stick` is on, so a pad without an analog stick can play. It turns the digital D-Pad off; set it to `disabled` for a game that uses it.

`Count Per Op` is 0 and the 4:3 resolution is 640x480. A higher `Count Per Op` made the game run slower.
